# GridsApps Bootstrap Components

Day 07 project: interactive Bootstrap 5.3.3 components built without custom JavaScript.

## Components

- **Offcanvas navbar:** a slide-in menu with links to the page sections and a Contact button.
- **Modal form:** a contact form with Bootstrap validation styles and a static alert.
- **FAQ accordion:** three questions, one open at a time.

## Tech Stack

HTML, Bootstrap 5.3.3 (CDN), and a custom stylesheet (`css/custom.css`).

## Accessibility Checks

- Keyboard: `Tab`, `Enter`, `Space`, and `Esc` work on all components.
- Focus stays inside the offcanvas and modal while they are open.
- No console errors.

## How to Run

1. Clone or download the repository.
2. Open `index.html` with Live Server or in a browser.
